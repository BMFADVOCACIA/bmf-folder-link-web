# BMF Folder Link Web

Pagina estatica de encaminhamento para o protocolo local `bmf-pasta://`, destinado a abrir pastas sincronizadas do OneDrive no Explorador do Windows.

Status: implementacao em preparacao. **GitHub Pages ainda nao foi ativado**.

A pagina nao autentica usuarios, nao consulta o OneDrive e nao hospeda documentos.
